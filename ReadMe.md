# Wedding

Сайт сервісу планування весільних подорожей в Івано-Франківську.

## Сторінки

- `index.html` – знайомство з Wedding, формати подорожі, підготовка та поради для двох.
- `about.html` – підхід до планування та кроки створення маршруту.
- `services.html` – маршрут, проживання та особливі моменти.
- `404.html` – сторінку не знайдено, з посиланнями на головну й контакти.
- `contact.html` – контакти та форма звернення.

## Локальний перегляд

Запустіть у цій папці `python -m http.server 8000` та відкрийте `http://localhost:8000` у браузері.

## Ресурси

HTML, CSS, SCSS та JavaScript з jQuery і Bootstrap. Зображення, іконки та відео збережені. Sacramento використовується для латинських рукописних написів; Marck Script забезпечує кирилицю в тому самому стеку шрифтів. Обидва підключаються через Google Fonts.

Умови ліцензування сторонніх бібліотек містяться в їхніх файлах. Загальний контекст і журнал стану проєкту розміщені в корені репозиторію.
